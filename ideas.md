# Chosen Direction — Signal Room

## Design Movement

Swiss International Typographic Style reinterpreted through a quiet observability dashboard: rigorous grids, purposeful labels, modular data cards, and restrained contrast. The visual language should feel like a high-trust control room for evidence, not a crypto landing page.

## Core Principles

1. **Evidence before spectacle.** Every visual flourish must clarify a source, state transition, or validator decision.
2. **Precision with warmth.** Dense technical detail is softened by generous spacing, human copy, and subtle paper-like texture.
3. **Asymmetric hierarchy.** The composition uses a left rail, offset modules, and anchored callouts instead of a generic centered marketing stack.
4. **State is visible.** Statuses, confidence, source count, and challenge history are treated as first-class visual objects.

## Color Philosophy

The base is near-black graphite (#101312), chosen to make the evidence surface feel deliberate and focused. A pale mineral field (#E9ECE4) provides the reading surface for explanations. The ownable signal color is acid chartreuse (#D5F25B), used sparingly for verified state, active connectors, and key metrics. Soft cyan (#8FD5D0) marks external observation, while warm coral (#FF826C) marks uncertainty or challenge. Color should encode state, never decoration.

## Layout Paradigm

An observability canvas: a sticky left rail names the system, while the main content progresses through a wide hero, evidence pipeline, split proof modules, and a final call-to-action. Sections are intentionally offset and interlocked, with connector lines and short labels creating continuity across the page.

## Signature Elements

- A vertical “evidence rail” with rotating section labels and a pulsing quorum marker.
- Thin connector lines that visually route sources into the contract result.
- Monospaced state chips and confidence meters that make the contract feel inspectable.

## Interaction Philosophy

Interactions should behave like instruments: immediate, legible, and stateful. Hovering a source highlights its route into the adjudication node. Tapping a verdict toggles between the human-readable explanation and the machine-checkable predicate. Buttons feel like commits, not promotions.

## Animation

Use only transform and opacity for motion, with 180–260ms snappy easing. On first load, reveal the evidence pipeline in a 50ms stagger. Let connector lines fade in before status chips. Hover states should raise modules by 2px and brighten the signal color. Respect reduced-motion preferences and never animate core reading content continuously.

## Typography System

Use **Space Grotesk** for display and UI labels, paired with **IBM Plex Mono** for contract identifiers, source counts, and code-like metadata. Headlines are compact, slightly tight, and sentence-cased. Body copy uses readable 17–18px text with a 1.55 line-height. Monospace labels are uppercase with generous tracking.

## Brand Essence

EvidenceQuorum is the verifiable evidence layer for builders who need real-world claims to become inspectable on-chain state. Personality: **measured, rigorous, quietly bold**.

## Brand Voice

Headlines are declarative and specific. CTAs are invitations to inspect or build, never hype. Microcopy names what the user can verify.

- “Consensus for claims that code cannot settle.”
- “Inspect the evidence path.”

## Wordmark & Logo

The mark is a three-node quorum glyph: two small source points converge through a narrow channel into a larger square result node. It should be rendered as a bold geometric symbol without text, with the left source pair slightly offset to imply independent validators.

## Signature Brand Color

**Quorum Lime — #D5F25B.** It is bright enough to read as a verified signal on graphite, but unusual enough to own the visual identity. Use it for consensus, not for general accents.
